Add Project — from GitHub

The repository is cloned into the manager's apps folder, then managed like any other app.

Add Project — from a local folder

Register a folder that already exists on this machine. It is managed in place — nothing is copied or moved, and removing the project later only unregisters it; the folder is never deleted.

Folder path

Full absolute path required — ~ is not expanded. The folder must be mounted into the manager container at the same absolute path; see the volumes section of the manager's docker-compose.yml.

If the folder is a git repository with a GitHub remote, it gets the full feature set — commit polling, GitHub Actions watching and pull-based deploys — just like a cloned project. Auto-deploy pulls and rebuilds in this folder: uncommitted changes are never overwritten — a conflicting pull fails the deployment instead. Without a git remote the project can still be started, stopped and rebuilt, but nothing can be watched or pulled.
